À propos de PPEI

PPEI (Portfolio d'applications Python pour Élus et Institutions) est développé par Philippe PETIT. Chaque application s'appuie sur des données publiques ouvertes (CEREMA, URSSAF, INSEE, API Géo) et vise à rendre ces données lisibles et exploitables par des élus et des agents qui n'ont pas de formation en analyse de données.

Les applications sont disponibles gratuitement, en version Windows et/ou en version Android selon les modules. Aucune donnée personnelle n'est collectée par l'éditeur.
